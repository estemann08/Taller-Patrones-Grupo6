## Estructura del Repositorio
El repositorio contiene los 4 proyectos desarrollados en Java:

1. `Proyecto Parqueadero 1 - Strategy` (Versión inicial con defecto OCP)
2. `Proyecto Parqueadero 2 - Strategy Refactorizada` (Solución aplicando el patrón Strategy)
3. `Proyecto Parqueadero 3 - State` (Versión inicial del ciclo de vida)
4. `Proyecto Parqueadero 4 - State Refactorizada` (Solución aplicando el patrón State)


## Instrucciones de Ejecución:

Cada proyecto es independiente y se puede abrir en cualquier IDE (como VS Code o IntelliJ IDEA):
1. Abre la carpeta del proyecto que deseas ejecutar.
2. Localiza la clase `Main.java` dentro de la ruta `src`.
3. Ejecuta el archivo para ver la simulación en consola del parqueadero.
